## New Features

### 1. Socialite (OAuth)
- Full OAuth provider system (`auth/socialite`)
- Built-in support for **Google** and **GitHub**
- Extensible `Provider` interface + `Manager`
- Service provider for easy registration
- Clean redirect + callback flow

**New file**: `docs/guide/socialite.md`

### 2. Two-Factor Authentication (2FA)
- Pure-Go TOTP implementation (no external dependencies)
- `GenerateSecret()`, `GenerateTOTPCode()`, `VerifyTOTP()` with clock skew support
- QR code URL generation for authenticator apps
- Integrated with Fortify routes

### 3. Account Lockout
- `auth.Lockout` manager
- Configurable max attempts + lockout duration
- Automatic locking after brute-force attempts
- Works seamlessly with `SessionGuard`

### 4. Advanced ORM Capabilities (Massive Expansion)
- **Polymorphic Relations** — `MorphOne`, `MorphMany`, `MorphTo` with eager loading and morph map registration
- **HasOneThrough / HasManyThrough** — full support with tag-based configuration
- **Attribute Casting** — 6 built-in casts (`datetime`, `json`, `bool`, `int`, `float`, `string`) + `Castable` interface
- **Accessors & Mutators** — `GetXxxAttribute()` / `SetXxxAttribute()` magic methods + `GetModelAttribute` / `SetModelAttribute` helpers
- **Relation Touching** — `$touches` interface for automatic parent timestamp updates
- **Upsert** — `Builder.Upsert()` with ON DUPLICATE KEY support
- **Pessimistic Locking** — `LockForUpdate()` and `SharedLock()` on queries and models
- **Local Scope Auto-Discovery** — `scopeXxx()` methods now auto-detected
- **Chunk / Lazy Processing** — `ModelQuery.Chunk(size, fn)` for large datasets

**Heavily updated**: `docs/guide/orm.md`

### 5. Authentication Enhancements
- Remember Me tokens (via `SessionGuard.Login(user, true)`)
- Full Socialite integration
- Improved Fortify 2FA support
- Account lockout integration

**Updated**: `docs/guide/authentication.md`

### 6. Routing & HTTP Improvements
- **Signed URLs** + `TemporarySignedRoute` + `ValidateSignature` middleware
- **Advanced Rate Limiting** — named limiters, per-user throttling, `ThrottleNamed()`
- **Full FormRequest** — `Messages()`, `Attributes()`, `PrepareForValidation()`, `PassedValidation()`, `FailedValidation()` hooks

**Updated**: `docs/guide/routing.md`

### 7. Testing Utilities
- `TestCase.ActingAs(user)` — Laravel-style authenticated requests
- File upload testing (`Upload()`)
- Advanced JSON assertions (`AssertJson`, `AssertJsonStructure`)
- Improved database assertions

**New file**: `docs/guide/testing.md`

### 8. Artisan Command Explosion
Dozens of new or completed commands:
- `make:mail`, `make:event`, `make:listener`, `make:policy`, `make:resource`, `make:job`, `make:notification`, `make:test`
- `cache:clear`, `cache:forget`
- `config:cache`, `config:clear`
- `view:clear`
- `queue:retry`, `queue:failed`, `queue:flush`
- `schedule:list`

All major generators and operational commands are now available.

### 9. Notification Channels
- New **SlackChannel** added
- Architecture ready for easy addition of more channels (SMS, etc.)

### 10. Ecosystem Foundations (Nice-to-Haves)
- **Inertia.js** support (`http/inertia`)
- **Livewire** equivalent foundation
- **Octane** high-performance server stub
- **Scout** full-text search manager
- **Cashier** billing foundation
- **Telescope / Pulse** debugging panel
- **Prometheus** metrics exporter
